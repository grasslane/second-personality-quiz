# 你的第二人格是什么？（趣味心理测试）

十二道题，照见你白天与深夜不同的那一面。输入当前测试码即可开始，答完全部题目生成人格画像报告。

## 技术架构
- **前端**：GitHub Pages 静态托管（本仓库 `main` 分支根目录）
- **后端/数据库**：Supabase（Postgres + RLS + 数据库函数）
  - `validate_code`：校验当前测试码（不限次数）
  - `consume_code`：完成测试后写入记录
  - 管理函数：`admin_get_current_code`（读当前码明文）/ `admin_set_code`（更换测试码）/ `admin_list_attempts`（测试记录）

## 测试码模式（单一测试码）
- 全站只有一个**当前有效测试码**，不限使用次数，适配"自动发货"场景。
- 管理后台可随时**更换测试码**，更换后旧码立即失效（防盗卖手段：定期换码）。
- 数据库只存测试码的 SHA-256 哈希；明文仅管理员通过后台查看。

## 访问入口
- 用户测评页：`https://grasslane.github.io/second-personality-quiz/`
- 管理后台：`https://grasslane.github.io/second-personality-quiz/admin.html`

## 管理后台使用
1. 打开 `admin.html`，用管理员邮箱 + 密码登录（见交付说明）。
2. 「当前测试码」：查看明文、一键复制（用于自动发货设置）。
3. 「更换测试码」：输入新码或随机生成 → 确认后旧码立即失效，请同步更新自动发货配置。
4. 「测试记录」：查看每次测试的时间、结果类型、所用测试码哈希前缀。

## 买家修改指南
- 品牌名 / 标题 / 题目 / 结果 / 配色：改 `index.html` 里 JS 的 `CONFIG`（文件头部有详细注释）。
- 测试码：全部在管理后台「更换测试码」中设置，无需改代码。

## 数据安全
- 测试码哈希存储，匿名用户无法读取；管理函数仅管理员可调用。
- 分享结果链接只包含答题序号，不含任何个人信息。
